# Extrator de Hashtags

Projeto simples em Java que encontra hashtags dentro de um texto usando Regex.

## Como funciona

O programa:

- Recebe um texto digitado pelo usuário
- Procura palavras iniciadas com `#`
- Armazena as hashtags encontradas em uma lista
- Exibe todas as hashtags encontradas

## Exemplo

Entrada:

```text
Estou estudando #Java e aprendendo #Regex
```

Saída:

```text
Hashtags encontradas: #Java, #Regex
```

## Tecnologias

- Java
- Regex (Expressões Regulares)
- ArrayList
